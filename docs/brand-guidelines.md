# DomScout identity

Original concept: a root and its suffix. A cut orange D carries the root; the detached square represents the extension. No stock emblem, magnifying glass, globe, shield or hexagon. This is original artwork, not trademark clearance.

Use `public/brand/logo-light.svg` on light ground, logo-dark.svg on charcoal, icon.svg when the wordmark cannot fit. SVGs contain editable vector geometry and an embedded licensed font for portable wordmarks. Keep one square's width clear around the mark. Smallest icon 16px; use 32px or larger when possible. PNG exports are browser-rasterized from the original SVGs, never fabricated application proof.

Assets: logo-light/dark SVG + PNG, wordmark-light/dark SVG + PNG, icon/icon-dark SVG, app-192/app-512 PNG, favicon-32 PNG, public/favicon.ico; og/social/github-preview SVG + PNG. Source generator: scripts/brand-assets.py. Exporter: scripts/export-brand.mjs.

Palette and typography: DESIGN.md and public/style.css :root. Orange #F97316 for large identity geometry; #C2410C for accessible action text/buttons. Charcoal #18181B, white #FFFFFF and neutral #F7F8FA. Text uses IBM Plex Sans, self-hosted from official Google Fonts with OFL at public/brand/OFL.txt. The Google Fonts source is https://github.com/google/fonts/tree/main/ofl/ibmplexsans . All navigation glyphs are original simple SVG paths; no third-party component code or logo assets copied.

No demo video, narration, storyboard, MP4 or video assets produced.
